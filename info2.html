Le conjugueur automatique donne une conjugaison en utilisant les informations données.
Le radical est la base du verbe. Il est l'équivalent d'un identifiant pour le verbe. Par éxemple, le radical "rem" pour le verbe "hu rema".
La conjugaison est la manière dont le verbe décrit. Les accronimes correspondent à des lignes et collonnes du tableau de conjugaison :
  • Temps : Passé, Présent, Futur, Contextuel, Subjonctif, Impératif
  • Mode : Parfait, Imparfait, Conditionnel
  • Sous-mode : Normal, Participe
  • Forme : Affirmative, Négative
Le sujet est l'acteur. On le désigne avec trois particules dont la dernière est séparée par la virgule :
  • Première (p/n) : "p" pour les personnes, "n" pour les noms
  • Deuxième (1à9) : Pour les numéros de personnes et de classes nominales
  • Troisième (s/p) : "s" pour le singulier, "p" pour le plusiel
L'objet est la cible. On le désigne de la mème manière que pour le sujet.
La dérivation désigne la manière dont le verbe est décliné pour indiquer un autre point de vue.
